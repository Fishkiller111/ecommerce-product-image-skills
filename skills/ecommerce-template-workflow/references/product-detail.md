# 商品详情图

将真实商品、经过核实的资料和独立背景排成本地详情图。用户说「做详情图／详情页」且未限定一张时，按现有素材制作一组手机端竖图。指定「只做成分图」「只要参数图」时只制作相应一屏。风格截图用来观察版式、衬底和视线顺序，本次原照、包装和用户资料用来确定商品与文字。

## 确定风格和屏序

同组图片默认同宽 790 px，画幅随每屏内容调整。首屏先讲产品是什么，接着按资料安排产品特点、成分或使用场景，再安排使用说明、包装细节和参数。购买前必须知道的限制可以前置。两项内容回答同一个问题时可以合屏，资料不足时可省去中间段落。一组图无需凑固定屏数。

先从本品资料提取文案，再按参考图决定布局。遇到同类软膏参考时，优先看可公开访问的完整详情长图，记录首屏讲什么、后续屏如何安排说明与参数，以及标签和衬底怎样延续背景颜色。可公开看到的首屏或单张图只用来判断其可见部分。参考商品的品牌、成分、功效、用量、疗程、规格和资质属于该商品，本品只采用能对应到实拍包装、说明书或用户资料的内容。

两款软膏详情的排版参考：

- 琴逸堂用大标题和盒、管实拍开场，再把场景、卖点与成分分屏。同组标签、圆角卡和背景共用绿色系，常规克重列于参数区。[琴逸堂商品详情](https://detail.tmall.com/item.htm?id=677909551843)
- 999 皮炎平分开呈现包装换新、成分、产品展示与说明书。包装细节用局部照片和短说明左右交替，用法和参数用浅底文字与表格。做本品时逐项核对当前 SKU 的盒、管、规格和说明书。[999 商品详情](https://detail.tmall.com/item.htm?id=679973966790)

- **文案先分主次。** 先答「这是什么、与同类有什么经核实的区别」，使用一个明确标题和必要的短副标题。只有产品名称和类型可证实时，就把两者讲清楚。普通净含量、数量、尺寸和贮藏是参数，放在后段小字号。只有资料能证明某个数字确实解释核心差异时才放大它。软膏包装上的产品类型可以照录，不能从品类名扩写成治疗范围、见效时间或配方优越性。
- **首屏**让标题、补充文案与实拍形成一个紧密的阅读组，沿用一条主要对齐线。放大商品和辨识度高的包装正面。横盒可占画幅约 75–90%，竖盒和软管可在一侧陈列，另一侧放短说明。标题已经讲清楚时，省略重复页眉、标签和卖点卡。
- **说明屏**一屏一个任务，排在核心产品介绍后面。大标题说明本屏主题，按内容安排真实实拍、注意事项或有资料支持的步骤。能核对步数、频次和用量时再展示。正文优先于列名，同一句不要拆成重复的标签和正文。规格与贮藏放后段说明栏或参数屏。
- **信息组件融入背景。** 背景安静的地方可以直接排字。复杂背景优先局部柔化，用原布景同色系的浅雾或深雾增加字的可读性，保留原背景的色温和明暗渐变。需要分行时用低对比细线和一致的缩进。实色白卡、亮描边、突兀的圆角和重阴影会打断场景，只有参考的材质和版式确实需要时才采用。
- **控制空白**。在手机宽度预览里沿阅读顺序看标题、重点信息、商品和说明的间距。若中间出现接近画高六分之一的断层，优先放大商品、移动信息卡、改变落脚点或裁掉多余场景。保留正常边距，素材少时做紧凑的一屏或减少屏数。没有足够实拍和文案时避免重复堆叠同一商品或补成分、功效。

## 场景首屏与商品保真

1. **先排内容和实物。** 为标题、重点数字、商品和信息条定区域，再确定原照片能成立的角度、台面落点和来光方向。盒与管分拍时用两张真实透明层定位。商品主印字留全，说明卡不盖住包装。
2. **按原商品配背景。** 用[独立背景生成](image-generation.md#生成背景或场景)生成无字无商品的满幅布景，或使用用户提供的独立场景。提示词写明目标画幅、台面的相对高度和宽度、相机角度、原商品的主色与反光材质、主光方向，以及每个文字区需要的明度。以弧形玻璃、渐层光或展台边缘连接各区，避免中央出现大块纯背景。现有照片与台面透视或光向冲突时，优先换背景。资源不足时将渐变底结果标为版式草图。
3. **本地合成和调光。** 保留原透明图，以等比缩放、平移或必要的旋转摆位。商品的接触阴影与投影分别画在下层。对照实物亮面、暗面和台面反光，微调商品曝光、冷暖和左右受光；保持品牌配色可辨、白区不过曝、深色印字不糊，透明轮廓和包装印刷细节保持原样。优先匹配背景，必要时用 `light` 小幅修正商品副本，或按用户要求关闭调光。文字在本地排版。商品图、正式文案和 Canny 导图留在本机。
4. **两次比较。** Canny 导图从原商品摆位层提取轮廓与印刷边。开启调光时，复核 JSON 同时记录透明通道是否一致、可见区域最大通道变化、与原印刷边在 1 像素邻域内未匹配的数量。另以调光后图层及其下背景为基准，比对成图的 RGB 和 Canny，检测遮盖和误叠。前一项用于观察调光影响，后一项差异应为 0。回看主印字、条码、边缘及接触阴影，发现轮廓漂移、印字不清或贴纸感时调整并重出。

| 屏 | 构图 | 素材与核对 |
| --- | --- | --- |
| 首屏 `hero` | 一个主标题和大幅实拍占据主要画幅。横盒可用上文下图，竖盒可用左右并置。有充分依据的差异点才单独强调。 | 本次原照或已核对的透明图，单独强调的信息记录出处。 |
| 成分 `ingredients` | 用 `layout: "grid"` 按项排材料图和名称，主题清楚时无需重复首屏商品。同组统一形状、取景与字号。 | 成分名以本商品配料表或说明书为准，使用核对过的对应材料图和部位。没有可靠材料图时用文字。示意图应按需标注「成分示意」，不当作实拍，不从原料推导浓度、配比、功效或适用范围。 |
| 用法或注意事项 `usage` | 放大实际操作、质地或手持图。用法或注意事项有可靠文字时可采用满幅场景，实拍与说明卡并置。 | 真实使用图和已确认的该商品说明。只有外包装时逐字核对能辨认的内容；无法确认的动作、对象、用量和频次不写。 |
| 参数 `specs` | 用 `layout: "table"` 在同色系浅底上让字段与值分列、细线分行。根据字段拆屏，规格数字和单位完整显示。 | 从本次包装、说明书或已核实的资料录入当前 SKU 的参数。只显示已知项。 |
| 实拍 `gallery` | 用 `layout: "alternating"` 左右交替排列局部近照和一句短说明。纯图片区沿用浅底大图，宽包装可独立整行。 | 使用本品照片，保持原始比例。局部图可从足够清晰的本品原照裁取，内容对应实际可见细节。需要看小字时使用清晰近拍，避免压进窄栏。 |
| 资质／检测 `documents` | 资料原件等比置入浅色卡框，有需要可分屏突出单份文件。检测依据可独立于用法放同组，标题直接标示实际报告主题。 | 仅使用用户提供且确认可公开、与当前商品或主体对应的真实文件页。核对机构、适用对象、报告日期和有效期。缺少材料时略过该屏。检测或资质图自始至终使用原件，保留页内文字，不用风格截图的证书、宣称或印章。 |

包装独立成层。可使用本地抠图或已经验边、调色的透明 PNG。基础版式可用[商品拼图流程](product-collage.md)中的透明组合，场景首屏优先分别摆放。白色包装、盖子、管口、品牌、文字、条码和规格在原图与成品间逐一比对。

## 交付用脚本

Agent 在用户输出目录内写 UTF-8 方案，按需要填入各屏。用户只需给原照、实际资料和目标风格。相对路径以方案文件所在目录为准。下例展示有明确素材出处的包装细节和规格，接在首屏与适用的说明屏之后。

```json
{
  "palette": "sand",
  "width": 790,
  "pages": [
    {"kind": "gallery", "layout": "alternating", "title": "包装细节", "items": [
      {"label": "正面", "text": "包装标注产品名称", "image": "assets/front.jpg", "source": "用户提供的正面实拍"},
      {"label": "侧面", "text": "规格与贮藏信息见侧面", "image": "assets/side.jpg", "source": "用户提供的侧面实拍"}
    ]},
    {"kind": "specs", "layout": "table", "title": "产品参数", "items": [
      {"label": "规格", "text": "18g/支", "source": "本品包装侧面"}
    ]}
  ]
}
```

- 一组为 1–12 屏。每屏支持 `kind`、`title`、`subtitle`、`items`。条目用 `label`、`text`、`image` 和可选 `source`。用 `source` 在复核 JSON 记下资料出处，例如实拍包装侧面或说明书页码。这个字段只进入复核记录。
- `hero` 的文字卡最多 2 项，可省略。成分最多 6 项，每项 `label` 填成分名，`image` 和 `text` 按实际素材选填。`usage` 最多 4 项，可有一项使用实拍。参数最多 7 行，每行提供标签与值。实拍每屏最多 3 项，资质最多 4 项，每项必须给图。`alternating` 的实拍另需 `label` 或 `text`，短说明优先。
- `ingredients` 用 `grid` 时可单独呈现成分图或文案，无需 `product`。`hero` 使用 `product` 或独立 `product_layers`。省略 `layout` 的旧方案继续使用原有排版。为 `grid` 提供背景时选择明朗、对比柔和的空景。
- 默认为 `heritage`（米白、暖金、松绿），也可选 `sage`、`sand`、`ocean`、`rose`、`lavender`。宽度支持 600–1600。首屏、成分、资质与没有使用实拍的商品用法屏可指定 `background`，使用独立无字场景。参数与实拍用清晰浅底。
- 场景首屏的 `background` 指向独立空景，`product_layers` 可分别安排 1–3 张透明商品图。每项有 `image`、`anchor`（相对画布的商品横向中心、接触台面的底端）、`height`（商品高度占画布的比例）、`angle`（可选，逆时针为正）。按从后到前的顺序写。例如一项可写为 `{"image":"assets/carton.png","anchor":[0.43,0.84],"height":0.55,"angle":0}`。指定这些图层时该首屏可省略顶层 `product`。
- 参考图文场景在 `hero` 或无使用实拍的 `usage` 上填写 `scene_layout`。使用 4:5 满幅背景。可选 `tone` 为 `dark` 或 `light`（默认首屏深色、说明屏浅色），`header` 和 `marker` 为可选的页眉文字。`copy_position` 默认 `above`，适合横盒，图层底端可从画高 0.78 左右起调。竖盒可选 `left` 或 `right`，商品放文字的另一侧。上下位置以实际台面为准。
- 有标题和短副标题的首屏可以省去条目。`scene_layout` 的首屏可加最多四条有用说明，`highlight` 可选，字段为 `value`、`label`、`source`。日常规格写到 `scene_layout.footer`（`text` 和 `source`）或独立参数屏。说明屏用 `items` 排最多四条核实过的说明，可只填正文 `text`。柔化底用所在区域的背景生成，文字密度和对比度仍以实际 PNG 为准。
- `scene_layout.light` 可填 `{"exposure":0.08,"warmth":0.03,"falloff":0.10}`，三项默认 0。正曝光提亮，正冷暖变暖，正 `falloff` 表示左亮右暗并让投影偏右。曝光和左右差各限于 ±0.20，冷暖限于 ±0.12。先按场景试小幅度、看原图和成图再调。这是确定性光色修正，原素材不改写。
- 完整详情页默认运行 `--long`，同时保留每屏 PNG 和 `详情复核.json`。用户只要单屏或分屏图时可省略 `--long`。若一屏文案塞不下，拆屏或重新排版，保留原字、数字和顺序。

脚本复用同级 `psb-template-product-swap` 的本机抠图和字体，商品边缘检查使用 `opencv-python-headless`。使用装好这两组依赖的 Python 3.12，或用 `PSB_PYTHON` 指定已有解释器。指定 `WORKFLOW_DIR` 及方案路径后运行：

```bash
DETAIL_PYTHON="${PSB_PYTHON:-python3.12}"
"$DETAIL_PYTHON" "$WORKFLOW_DIR/scripts/render_detail_series.py" "$DETAIL_PLAN" \
  --out outputs/product-detail --long
```

macOS 已装 `uv`、解释器尚缺依赖时，可用 `uv run --python 3.12 --with-requirements "$WORKFLOW_DIR/../psb-template-product-swap/requirements.txt" --with 'opencv-python-headless>=4.8,<5' python` 运行同一脚本。在 Windows 的现有环境中安装同一 OpenCV 包。

```powershell
& $env:PSB_PYTHON (Join-Path $WorkflowDir 'scripts\render_detail_series.py') $DetailPlan `
  --out outputs/product-detail --long
```

原先的 `render_detail.py <原图> --text-json <文案>` 仍用于明确要求沿用 `hero` 或 `features` 的基础单图版式。增强详情图走本页方案脚本。

## 验收

把长图缩到约 390 px 宽从头读到尾。先检查第一眼读到的是不是商品和核心信息，然后逐屏检查标题、材料图、近照和正文是否各自回答一个清楚的问题。检查图文留白、浅底与前后屏的色彩衔接，以及说明区的对比度。再在原尺寸核对轮廓、包装主印字、条码和文案出处，检查商品亮暗、色温、接触阴影与台面是否一致。逐屏比对长图顺序和接缝，确认参数和准备上架的 SKU 对应。素材不足而省略的屏在交付里说明。文字无法核对的图可作为版式样张，清晰度检查与预览状态写进复核记录。
