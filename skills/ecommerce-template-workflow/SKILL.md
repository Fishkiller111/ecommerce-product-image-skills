# 商品主图、详情图与拼图

用户提供真实商品原图、需要的摆放方式或文案即可，不要求提供 SKU、编写 JSON 或操作 Photoshop。默认在本机处理，交付能打开的 PNG；能看版式不等于可以上架，不能放松商品保真和文案复核。

## 按用户说的类型选择结果

- **商品主图**：沿用下方固定 PSB 母版换品换文案流程，输出 1440×1440 主图；不要套用详情图画布。
- **商品详情／商品详情图**：把真实商品与美化背景、标题和说明文字组合，走 [商品详情图流程](references/product-detail.md)；不要调用固定 PSB 主图套版冒充详情图。背景和布局可参考用户提供的风格图，但参考图里的商品和文案不自动成为本次素材或卖点。
- **拼图**：取本次两张真实商品原图，按用户指定的次序分别抠图并组合，走 [商品拼图流程](references/product-collage.md)。两件商品须自然落在同一支撑平面上，接触位置、光向和阴影一致，不能无支撑悬空；“图一在上图二在下”默认处理为同一平面上的前后错位，而不是图像上生硬竖向堆叠。按附件或指定图号摆放，不能按文件名换序。默认输出带接触阴影的透明组合及带地面背景的预览，不套 PSB 或编造商品。
- **明确需要多种结果**：分别执行所需流程；若用户说“先拼图，再出主图／详情”，先检查拼图，再使用其透明组合进入所需流程。各结果分别展示与复核，某一路失败不虚报另一路的状态。
- **未说明类型**：为兼容旧用法默认商品主图；出现“拼图”则走拼图流程，说“商品详情”则走详情图流程。原图与风格参考图无法区分时，只追问这一必要信息。

## 商品主图：默认使用原图在本机出图

1. **确认输入和文案。** 使用本次用户提供的真实原图，或用户确认过的透明 PNG；不要用截图缩略图、其他 SKU 的照片或 AI 重建图代替原图。找到与本技能同级的 `psb-template-product-swap`（安装器可能使用链接，必要时取真实路径），读取其 `SKILL.md`。默认不读取或调用 APIMart，不先做生成式白底图。普通“高清”“提亮”用本地基础增强，不重画包装或补写细字。
2. **写文案和创建唯一编号。** 按用户原字写 UTF-8 JSON：明确“顶部/上边框”用 `header`，未指明位置的主标题用 `hero_title`，明确“底部大字”用 `promo`。数字和汉字原样保留。已有明确位置的任务按原任务复跑。替换模板里未经确认的旧促销、品牌、保证和服务承诺；可用与原照相符的中性描述，不能自行加规格、功效、认证或价格。示例中性字段：`header` 为“商品展示”、`promo` 为“外观展示”、`badge` 为“商品\n展示”、`tag_1` 至 `tag_3` 用可见外观描述。先把文案写到 `outputs/psb-copy/<SKU>.json` 等独立位置；**不要预建套版输出的 SKU 子目录**，脚本会创建它来防覆盖。
3. **直接调用套版脚本。** 将 `PSB_SKILL_DIR` 设为套版技能目录绝对路径；已配置的解释器可用 `PSB_PYTHON` 指定。下面的 `SOURCE_IMAGE` / `SourceImage` 传入本次原图或真实透明图。实拍和普通透明 PNG 不加 `--prepared-cutout`：脚本可自动分割，已有透明背景时也可直接用。只有用户明确指定已确认的高清透明素材时才用 `--prepared-cutout`；它尺寸不足会拒绝，不能擅自换图或放大。只有用户明确要保留输入观感时才用 `--keep-product-look`。

   macOS（原图自动抠图用本机 Vision）：

   ```bash
   "$PSB_SKILL_DIR/run.sh" "$SOURCE_IMAGE" --sku "$SKU" --text-json "$COPY_JSON" --out "$OUT_ROOT"
   ```

   Windows PowerShell（按套版技能配置 Python 和 Windows 依赖，本机分割模型首次下载需要联网，但不上传商品图）：

   ```powershell
   & (Join-Path $env:PSB_SKILL_DIR 'run.bat') $SourceImage --sku $Sku --text-json $CopyJson --out $OutRoot
   ```

   `OUT_ROOT` / `OutRoot` 为项目的 `outputs/psb-template-swap-direct`。如已有**同一张原照**经目视核对的轮廓配置，可加 `--photo-profile <路径>`（脚本核对原图 SHA-256 与尺寸）；可检查已安装技能或项目源目录 `skills/psb-template-product-swap/examples/` 的已核对配置。不能仅凭文件名套用别图轮廓；没有匹配配置时走本机自动分割。不要把白底图当作透明图，也不要把白色包装当背景删除。
4. **打开结果确认。** 用脚本返回的 `preview` 找到实际生成的 1440×1440 主图；打开主图和透明素材，与原照核对包装文字、数量、比例、边缘（特别是白色包装、软管和盖子）和新旧文案。自动抠图漏掉部件、有白边或把包装抠空时，先用同图已核对轮廓或已确认的透明素材重跑；不能把缺件的图交为通过。套版成功后按下列状态交付，不把预览当上架成品。

## 商品主图交付状态

- **已生成主图预览**：展示真正的套版 PNG 和绝对路径，不只交文案、白底中间图或任务编号。保留原像素透明素材、文案 JSON 和 `03_复核说明.json`。图片不是可编辑的 PSB。即使包装看起来清楚，也要由使用者核对实物和活动后再上架。
- **原图细节不足**（`native-detail-insufficient`）：只要轮廓和商品完整，**仍展示已生成的套版图**，说明“仅看版式，勿上架”；原图小字不能通过插值变成可核实的文字。建议换同角度、未压缩的清晰近拍后重跑。不要因清晰度不过关而只交复核记录。
- **确实无法出图**：脚本报错、没有可用的原图或透明素材、分割后仍缺件，或模板/字体无法加载时，报告具体失败阶段，保留可用中间文件。不能虚报成图，也不能把失败的白底图当主图。

## 商品主图的生成式修复是可选分支

- 只有用户明确要求生成式修复或白底效果，并同意使用外部图像服务时，才读取 `ai-ecommerce-product-images/SKILL.md`；告知上传及可能计费，不输出凭据。默认本地套版不需要 API，也不必等生成式白底图通过复核。若本次同时要求套版，先尝试用真实原图完成本地预览；外部调用失败或 AI 包装保真失败，只拒绝 AI 素材，不取消已生成的原图套版预览，也不使用 AI 错字素材重试套版。
- AI 修复可能改写印字。不能确认的 AI 修复图仅在用户接受内部试样时，用 `--prepared-cutout --keep-product-look --ai-restored-preview` 做图内和文件名均标“勿上架”的样张；不能当成真实原片或可上架成品。基础增强无法恢复不可辨认细节，应优先补拍。
