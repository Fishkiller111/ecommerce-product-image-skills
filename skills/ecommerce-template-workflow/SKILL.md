# 商品修图与模板套版

用户只需提供商品原图和最终文案。默认使用项目固定抖音 PSB 母版，不改母版，也不要求用户编写 JSON、提供 SKU 或操作 Photoshop。每次创建独立输出目录，避免覆盖。

## 准备

- 找到本技能所在的已安装技能目录，再读取同级的 `ai-ecommerce-product-images/SKILL.md` 和 `psb-template-product-swap/SKILL.md`；安装器可能用符号链接，必要时使用真实路径。把 `PSB_SKILL_DIR` 设为后者的技能目录绝对路径，并在安装好依赖时把 `PSB_PYTHON` 设为对应解释器的绝对路径。前者负责商品图处理和保真检查，后者负责透明素材入模与本地排版。处理阶段按前者读取 APIMart 配置，凭据不写入输出、脚本或日志。使用 APIMart 会上传图片并可能计费；用户指定或已同意此工作流使用该服务时，按本次任务执行并提示费用。未配置 API、没有上传授权或用户拒绝时停止该分支并说明。
- 本流程只调用第一个技能的商品处理和检查部分，不生成其独立场景电商图；最终主图由第二个技能的固定模板产生。不要把白底图当成透明图传入 `--prepared-cutout`。
- 从用户自然语言提取模板文案，原样保留数字与文字；没有提供的内容不得自行补充功效、促销、认证或承诺。检查模板剩余文字，不适用或未经确认的内容替换为中性、可从原图核实的描述；无法确定则停止并说明。仅在文字位置确实无法合理判断时提问。
- 根据源文件和时间生成唯一 SKU；把对应 `hero_title`、`hero_subtitle`、`header`、`promo`、`badge`、`tag_1` 至 `tag_3` 写成 UTF-8 JSON。按用户意图映射位置，如“底部大字”用 `promo`。文案超出或遮挡时调整排版并检查成图。

## 执行

1. 以原图为商品事实来源。执行 `ai-ecommerce-product-images` 的白底保真处理及其逐项检查；若已有用户确认的高清透明素材，可直接检查并使用。白底图与原图对比品牌、文字、图案、颜色、比例、商品数量、轮廓和可见细节。生成式修复可能改写内容；不能辨认的文字不能视作核对通过。保真不通过时按该技能重试，仍失败则标记 `REJECTED`，停止正式流程并说明，不得称为实拍或可上架。
2. 将通过检查的素材转换为真正带 alpha 的透明 PNG，不能简单地把白色当透明色以免损坏白色包装。使用套版技能的 `scripts/cutout_product.py`：macOS 可执行 `"$PSB_PYTHON" "$PSB_SKILL_DIR/scripts/cutout_product.py" 白底图.png 透明图.png`；Windows PowerShell 使用 `& $env:PSB_PYTHON (Join-Path $env:PSB_SKILL_DIR "scripts\cutout_product.py") "白底图.png" "透明图.png"`。Windows 须先安装 `requirements-windows.txt`；仅对源图应用本地蒙版，输出不覆盖现有文件。检查白色包装、边缘、孔洞和阴影，确保商品内容未改变。白底保真图不是透明输入；透明素材再次对照原图。保存处理前后素材。对于已经确认的透明素材不再重新抠图。
3. 用透明素材、唯一 SKU 和 JSON 调用已安装的 `psb-template-product-swap/run.sh`（macOS）或 `run.bat`（Windows），或直接以配置好的 Python 执行 `scripts/render_sku.py`；均使用技能目录绝对路径，使用 `--prepared-cutout`。商品已调光增强并确认外观时附加 `--keep-product-look` 避免重复增强；否则按套版技能默认增强。不要把生成式高清素材当作原始像素；须结合源照片主体尺寸判断清晰度。
4. 读取复核 JSON 的 `detail_review`、`publication`，并以 100% 大小检查最终图、包装细字、边缘、光晕、位置与文案。照片需放大造成原始细节不足、细字模糊或保真无法确认时不得交付为上架成品。

## 失败与试样

- 提供未压缩近拍或用户核实过的高清透明素材是制作上架图的优先方案；不靠增加锐度假造细节。
- 若用户要求 AI 修复、现有素材不足，或需要展示修复方向：仅对单独商品做生成式修复，不能重绘模板或文案。保真失败或有不可核实的印字时不进入正式分支。**只有用户要求或接受内部效果样张时**，方可用套版技能的 `--prepared-cutout --keep-product-look --ai-restored-preview` 生成图上和文件名均标注“勿上架”的样张，明确哪些细节不可靠；样张不是白底保真图，也不是实拍或可上架成品。正式保真检查失败不得因有样张而标记通过。
- 上传、API、分割、模板、字体或保真检查失败时，保留可用中间文件，明确失败阶段和原因，不虚报完成。

## 交付

展示最终 PNG 并给出绝对路径；保留透明素材、用户文案 JSON 与复核 JSON。说明成图为扁平 PNG 非可编辑 PSB，以及实际状态：通过人工检查、清晰度不足、保真未通过或 AI 勿上架样张。只有实际检查过才能说已核对；提示上架前仍需人工对照实物与促销条件。未经核实的声明不能上架。
