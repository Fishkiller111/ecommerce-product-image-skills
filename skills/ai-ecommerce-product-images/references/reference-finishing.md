# 参考调色与修边

## 选择底稿

- 默认复用有透明背景的源图 alpha，或生成 macOS Vision、本地 rembg 蒙版。接近不透明的 RGBA 白底图仍需分割。自动蒙版没识别到商品时可换 `--backend vision`、`--backend rembg --model u2net` 或 `u2netp`，也可以直接描边。rembg 使用已安装的本地权重。
- 色差明显、背景简单时可比较 `--backend grabcut --rect X Y WIDTH HEIGHT`。矩形用校正 EXIF 方向后的原图像素，须包住完整商品并留一点背景。检查桌面是否一起被选。
- 工作中使用原始像素和原图方向。默认居中等比、主体最长边约占方图的 86%，放大最多 2 倍。可用 `--size`、`--fill`、`--upscale-limit 1` 调整。亮度与色彩校正默认开启，`--strength` 默认 1，可按实际观感在 0 至 1.5 内调整。仅在用户要求保留曝光和原色时使用 0。锐化用 `--sharpness` 单独控制。
- `review.json` 记录 `color_space`、`tone` 和 `edge`。默认曝光根据主体各像素最高通道的第 90 和第 98 百分位估计高光余量，限制高光提亮并保护深色印刷。检查报告中的亮度、色度中位数和曝光增益，再对照原照与成图。带 ICC 的照片先转换到 sRGB，取样图也在 sRGB 中读取数值。

## 按参考图取样

1. 商品相同时，可把对照图旋转到相同阅读方向以方便取样。成品仍沿用原照方向，除非用户另有要求。分别从两图的对应材质取几块中间调，记录 sRGB 中位数。取样避开边缘、字缝、强反光、纯色背景和阴影。比较同材质时可在亮暗两段分别取样。
2. 大字镀银、白色瓶盖等中性色各自取样。原照整体有偏色时，可用 `--neutral-rect LEFT TOP RIGHT BOTTOM` 在同一照明下选一块确认是白色或灰色的材质。选包材内部的均匀中间调，避开字、亮斑、阴影和轮廓。若偏色只发生在局部，用带 `region` 的 `palette` 单独校正。
3. `palette` 以原照像素的相近颜色为基准做局部校色，区域外继承基础调色。遇到严重欠曝或不同面受到不同光源影响时，从同款成品分别取主色、暗部和高光样本，逐面复调。色样影响到旁边细字或压平底纹时，缩小匹配范围或用 `region` 限制区域。
4. 跨品类案例可用于核对材质表现。金黄色或荧光包装应留出高光层次并看清深色字，深绿或藏蓝包装应留住深底与浅字的反差，白罐需要在白底上辨认盖沿、接缝和瓶身弧面。用户给的「成品案例图」中，`白底12.jpg` 对应高饱和黄绿硬盒，`白底4.png` 对应深绿印刷，`白底19.jpg` 对应白色圆罐。该目录的这些案例为白底成品，可据此验收白底观感；透明边缘还需换底复核。

## 精修轮廓

1. 在原照、白底和深灰底上看 100% 和局部放大图。硬盒两条长边有台阶时，在原照上沿真实边界标点。长直边可用局部亮度或颜色梯度找位置，然后平滑拟合；真实转角、折盖和轻微弧线用较密的点跟住。盒底应贴实体下沿，去掉下方桌面或投影。按顺时针或逆时针沿轮廓填 `outline`，渲染时会做亚像素抗锯齿。
2. 确认轮廓完整后，硬边锯齿可用 `--edge-mode opaque`。脚本只在透明区与实心区相邻处调整 alpha，并从两像素宽邻域恢复过渡带颜色。GrabCut 的硬蒙版在默认模式下会做此处理，Vision、rembg 和外部灰度蒙版保留原 alpha。已按亚像素描过的 `outline` 可用此模式修过渡带颜色，配方也可独立指定 `decontaminate_px`。`--edge-mode preserve` 保留蒙版的过渡。深浅底上都应检查白色折边、银箔和细小凸起。
3. 多物体、孔洞、软边或半透明区域用同尺寸灰度蒙版，黑为背景、白为实心、灰为部分透射或覆盖。在原图坐标上局部修改后用 `--mask`，轮廓配方省略 `outline` 和 `decontaminate_px`。保留真实软边和孔洞内的透明度，再叠于不同颜色的背景检查。
4. `--matte-blackpoint`、`--matte-whitepoint`、`--contract`、`--feather` 用于已确认的轻微蒙版问题。若源图仍可看见盒底、盖角或薄片而候选图缺失，先按实体外沿重画。若局部仍夹背景，可沿该处轮廓收回，避免伤及同图其他部件。

## 成品验收

| 对照 | 核验部位 |
| --- | --- |
| 白底图，100% | 外部背景为纯白，实体着边，无桌面投影、浮边、缺口。白包装的亮面、暗面和接缝仍可区分 |
| 深灰底预览，100%–200% | 顺着边线查看四角和长斜边。无灰圈、白边、毛刺及可见台阶。孔洞干净，软边过渡符合原照 |
| 原尺寸精修图与原照 | 重点检查印刷文字、条码、细纹和包装物理结构。颜色判断按已确认的同款参考或原照材质 |
| 白底与透明图 | 方图尺寸、主体位置一致，透明图在纯白上合成后和白底图逐像素相同 |

若脚本输出 `待人工复核`，完成上述检查并记录具体部位与结果。对照案例时可将原照、标准、白底和深底的同一段边线做成等倍率裁片，查看缩小后的整图也能看见的缺陷，再查被缩略图掩盖的像素边缘。

## 配方格式与复跑

取样调色依赖 `opencv-python-headless`，窄带去灰依赖 `scipy`。在本机 Python 环境准备相应依赖即可；使用已有的 `cv2` 时无需重复安装。

```json
{
  "source_sha256": "填入本张原图的 SHA-256",
  "outline": [[30.5, 25], [402, 22], [405, 270], [33, 273.5]],
  "decontaminate_px": 2,
  "palette": [
    {"source": [115, 92, 36], "target": [245, 214, 91], "radius_lab": [20, 12, 14]},
    {"source": [84, 82, 80], "target": [217, 216, 211], "region": [60, 120, 380, 220]}
  ]
}
```

`outline`、`palette` 和 `decontaminate_px` 均可按需省略。轮廓点与 `region` 坐标以 EXIF 校正后的完整原图为准。色样 `source` 和 `target` 是 RGB 三值，`radius_lab` 定义作用范围并可省略。脚本会自动加载 `examples/` 中设有 `"auto_apply": true` 且 SHA-256 与输入完全一致的配方。匹配后用 `--mask` 重描保留取样调色，只换轮廓；显式配方带有 `outline` 时先移除该字段再传入手工蒙版。图源更换或改变裁切后重新取坐标和色样。留存配方、参考图和最终核验状态。

```text
python <技能目录>/scripts/local_product.py <原图> --finish-recipe <精修配方.json> --out <新输出目录>
```

[盒装照片实测配方](../examples/carton-2f251bc.json)对应本次验证过的一张盒装原照。可以参考字段和采点密度。若使用同一张原照，能直接带此配方复跑；其他原图会在处理前因指纹不匹配而停止。配色按实际输出与参考图核验。

## 无藓膏金黄红框盒

广至德条码侧盒装的正面是明亮金黄，暗红印刷保留暖调，侧面金纸明显暗于正面，银字边接近中性色。对照时分别取样。金黄正面中间调约 `[249, 214, 84]`，红底约 `[135, 50, 40]`，侧面金纸中间调约 `[175, 130, 49]`，银字高光约 `[235, 234, 228]`。这些值来自同款标准，用来对照材质，保留各部位原有明暗、纹理、印字和条码反差。

[标准图原照配方](../examples/carton-6134fa.json)与[另一张条码侧原照配方](../examples/carton-barcode-second-view.json)已按原图指纹启用。遇到同款新照片，用这组目标色重新取原照对应色样并确定轮廓。验收时检查正面、红底、侧面及银边，确认 `tone.method` 为 `reference-palette`。其他商品按各自原照和标准校正。
