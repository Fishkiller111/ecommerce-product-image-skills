# 参考调色与修边

## 选择底稿

- 默认识别源图 alpha、macOS Vision 或本地 rembg。换用 `--backend vision`、`--backend rembg --model u2net` 或 `u2netp` 比较实际结果。rembg 仅加载已安装的本地权重；处理过程不下载模型。
- 色差明显、背景简单时可比较 `--backend grabcut --rect X Y WIDTH HEIGHT`。矩形用校正 EXIF 方向后的原图像素，须包住完整商品并留一点背景。检查桌面是否一起被选。
- 工作中使用原始像素和原图方向。默认居中等比、主体最长边约占方图的 86%，放大最多 2 倍。可用 `--size`、`--fill`、`--upscale-limit 1` 调整。亮度与色彩校正默认开启，`--strength` 默认 1，可按实际观感在 0 至 1.5 内调整。仅在用户要求保留曝光和原色时使用 0。锐化用 `--sharpness` 单独控制。
- `review.json` 的 `tone` 记录自适应校正或参考取样方式，以及同一主体区域原照和成图的亮度、色度中位数。指标用于确认变化方向，最终以原图与成图在同一底色上的视觉对照为准。

## 按参考图取样

1. 商品相同时，可把对照图旋转到相同阅读方向以方便取样。成品仍沿用原照方向，除非用户另有要求。分别从两图的对应材质取几块中间调，记录 sRGB 中位数。取样避开边缘、字缝、强反光、纯色背景和阴影。比较同材质时可在亮暗两段分别取样。
2. 大字镀银、白色瓶盖等中性色应视作独立样本。若同一色样也命中无关细字或另一材质，用 `region` 限定原照坐标中的有效区域。若字边产生光晕、颗粒变粗或底纹被压平，收窄色样范围、降低目标亮度或缩小区域，再复跑。参照物不同或色彩缺乏可靠对应时，只借鉴整体明暗和质感。
3. `palette` 以原照像素的相近颜色为基准做局部校色，区域外继承基础调色。先复核色相和曝光，再查看原尺寸素材中的文字对比度和纹理。原图本身不可辨认的部分如实记录。

## 精修轮廓

1. 在原照、白底和深灰底上看 100% 和局部放大图。硬盒两条长边有台阶时，在原照上沿真实边界标点。长直边可用局部亮度或颜色梯度找位置，然后平滑拟合；真实转角、折盖和轻微弧线用较密的点跟住。盒底应贴实体下沿，去掉下方桌面或投影。按顺时针或逆时针沿轮廓填 `outline`，渲染时会做亚像素抗锯齿。
2. 硬盒如仍有灰边，可对约 1–3 个原图像素的过渡带用 `decontaminate_px` 借用邻近的实心商品颜色，然后重看两种底色。白色折边、银箔和实际透明部件不能当背景去掉。多物体、有孔洞、软边或半透明时，在本地图像编辑器上制作同尺寸灰度蒙版，黑色为背景、白色为商品、灰色为半透明；使用 `--mask` 并省略 `outline` 和窄带去灰。
3. `--matte-blackpoint`、`--matte-whitepoint`、`--contract`、`--feather` 用于已确认的轻微蒙版问题。边界位置错了先重描；扩大羽化和全局内缩可能遮住真边和小部件。

## 配方格式与复跑

取样调色依赖 `opencv-python-headless`，窄带去灰依赖 `scipy`。在本机 Python 环境准备相应依赖即可；使用已有的 `cv2` 时无需重复安装。

```json
{
  "source_sha256": "填入本张原图的 SHA-256",
  "outline": [[30.5, 25], [402, 22], [405, 270], [33, 273.5]],
  "decontaminate_px": 2,
  "palette": [
    {"source": [115, 92, 36], "target": [245, 214, 91], "radius_lab": [20, 12, 14]},
    {"source": [84, 82, 80], "target": [217, 216, 211], "region": [60, 120, 380, 220]}
  ]
}
```

`outline`、`palette` 和 `decontaminate_px` 均可按需省略。轮廓点与 `region` 坐标以 EXIF 校正后的完整原图为准。色样 `source` 和 `target` 是 RGB 三值，`radius_lab` 定义作用范围并可省略。脚本会自动加载 `examples/` 中设有 `"auto_apply": true` 且 SHA-256 与输入完全一致的配方。匹配后用 `--mask` 重描保留取样调色，只换轮廓；显式配方带有 `outline` 时先移除该字段再传入手工蒙版。图源更换或改变裁切后重新取坐标和色样。留存配方、参考图和最终核验状态。

```text
python <技能目录>/scripts/local_product.py <原图> --finish-recipe <精修配方.json> --out <新输出目录>
```

[盒装照片实测配方](../examples/carton-2f251bc.json)对应本次验证过的一张盒装原照。可以参考字段和采点密度。若使用同一张原照，能直接带此配方复跑；其他原图会在处理前因指纹不匹配而停止。配色按实际输出与参考图核验。

## 无藓膏金黄红框盒

广至德条码侧盒装的正面是明亮金黄，暗红印刷保留暖调，侧面金纸明显暗于正面，银字边接近中性色。对照时分别取样。金黄正面中间调约 `[249, 214, 84]`，红底约 `[135, 50, 40]`，侧面金纸中间调约 `[175, 130, 49]`，银字高光约 `[235, 234, 228]`。这些值来自同款标准，用来对照材质，保留各部位原有明暗、纹理、印字和条码反差。

[标准图原照配方](../examples/carton-6134fa.json)与[另一张条码侧原照配方](../examples/carton-barcode-second-view.json)已按原图指纹启用。遇到同款新照片，用这组目标色重新取原照对应色样并确定轮廓。验收时检查正面、红底、侧面及银边，确认 `tone.method` 为 `reference-palette`。其他商品按各自原照和标准校正。
